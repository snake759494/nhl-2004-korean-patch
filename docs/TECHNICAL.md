# 기술 요약

영어 전용 글자 처리에 2바이트 코드를 추가했습니다. 선행 바이트 0x81–0x8F와 후행 바이트 0x80–0xFF를 한글 글리프로 연결하고, 8비트/16비트 문자 변환 및 글자 폭 계산 경로를 수정합니다. 이번 빌드의 한글 집합은 1,036자입니다.

SFN 및 경기용 FNTS 글꼴을 확장하며 원본 글리프와 팔레트를 보존합니다. 원본 영문 테두리와 비교하여 한글 본체 주변 윤곽 및 그림자를 생성합니다. 선수 이름의 대문자화·악센트 제거·이름 조합이 2바이트 코드를 분리하지 않도록 보정합니다.

BIGF와 RefPack으로 묶인 언어 표, FNG 표시 문구, TDB 선수/구단 자료와 일반 텍스트를 처리합니다. 데이터베이스 체크섬과 고정 필드 폭을 검사합니다. 이름 문자열은 필요한 구간에서 재배치하고 데이터 포인터를 수정합니다. 일부 팀 약칭은 데이터 검색 키를 보존하면서 표시 단계에서 변환합니다.

일반 제작진 텍스트의 태그와 열 구분을 보존합니다. 온라인 이용약관은 게임의 줄 버퍼 크기에 맞춰 줄바꿈합니다. 사전 읽기 컨테이너의 중첩 복사본에도 동일한 내용을 적용합니다. 문자 이미지 3개는 원본 크기·팔레트·자원 해시를 유지한 채 프로젝트 글꼴로 생성합니다.

확장된 파일은 원본 ISO의 DUMMY.PAD 공간에 배치하고 ISO9660과 UDF 양쪽 디렉터리를 갱신합니다. 출력 ISO에서 수정 파일을 다시 읽어 빌드 파일과 비교합니다.

자동 검사는 실제 게임 실행 확인을 대신하지 않습니다. TEST8까지의 경기/선수 이름/테두리는 사용자 확인을 받았으며, TEST9의 추가 번역은 실제 게임 확인 전입니다.
