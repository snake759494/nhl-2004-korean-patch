# PCSX2 16:9 와이드 패치

현재 정식 릴리즈 `v0.9.0-test9`의 한글 ISO 전용 파일은 **`SLUS-20756_AB775F59.pnach`**입니다. xdelta 파일과 별도로 같은 릴리즈에서 받습니다. ISO를 다시 만들 필요는 없습니다.

## 설치와 활성화 — PCSX2 2.x

1. xdelta를 원본 북미판 ISO에 적용하고 결과 한글 ISO를 PCSX2 게임 목록에 등록합니다.
2. 게임을 완전히 종료한 상태에서 PCSX2의 **도구 → 데이터 디렉터리 열기**로 실제 데이터 폴더를 엽니다. 설치형의 예시는 `문서/PCSX2`, 포터블은 PCSX2 실행 파일이 있는 폴더입니다. 사용자 설정에 따라 달라지므로 메뉴로 연 위치를 우선합니다.
3. 그 안의 **`patches`** 폴더에 `SLUS-20756_AB775F59.pnach`를 넣습니다. 폴더가 없으면 만듭니다. `.pnach.txt`로 저장되지 않았는지 확인합니다. 이 안내는 최신 형식의 `patches` 폴더용이며 `cheats`/`cheats_ws`에 중복 설치하지 않습니다.
4. 게임 목록에서 **한글 ISO 우클릭 → 속성 → 패치**를 열고 **`Widescreen 16:9`**를 선택합니다. 목록에 없으면 PCSX2를 다시 실행하고 게임 속성을 다시 엽니다. 패치 기능이 전역에서 비활성화돼 있으면 활성화합니다.
5. **속성 → 그래픽 → 디스플레이 → 화면 비율**을 **16:9**로 설정합니다. 패치에도 `gsaspectratio=16:9`가 있지만 직접 설정하면 버전/전역 설정의 차이를 줄일 수 있습니다. 확대/자르기는 기본값으로 둡니다. 화면 비율만 16:9로 바꾸면 가로로 늘어나기만 하므로 패치 선택도 필요합니다.
6. 이전 상태저장을 불러오지 말고 ISO를 새로 부팅합니다. 메모리 카드의 일반 게임 저장과 PCSX2 상태저장은 서로 다릅니다.

## 확인 및 문제 해결

- 게임 속성 또는 로그의 게임 식별자가 **SLUS-20756 / CRC AB775F59**인지 확인합니다. CRC는 ISO SHA-256과 다른 PCSX2 실행 파일 식별값입니다. 원본 영어판이나 다른 한글 빌드에 이 파일의 이름만 바꾸어 사용하지 마세요.
- PCSX2 로그에서 `Enabled patch: Widescreen 16:9`를 확인할 수 있습니다. 시험 환경은 PCSX2 v2.9.94입니다. 언어/버전에 따라 메뉴 이름이 조금 다를 수 있습니다.
- 같은 게임에 다른 와이드/카메라/FOV 패치가 있다면 비활성화합니다. 내장 와이드 패치와 수동 패치를 겹쳐 적용하지 마세요.
- 여전히 늘어나기만 하면 파일명, CRC, 실제 데이터 폴더, 패치 체크 상태를 확인한 뒤 완전히 종료하고 다시 부팅합니다.
- 검은 화면이나 새 빌드에서 문제가 생기면 아래 절차로 끈 뒤 해당 빌드와 함께 배포된 새 파일을 사용합니다.

## 비활성화와 원상복구

게임을 종료하고 속성의 `Widescreen 16:9` 체크를 해제합니다. 화면 비율을 **자동 4:3/3:2 또는 4:3**으로 되돌린 뒤 새로 부팅합니다. 필요하면 `patches`의 해당 파일을 밖으로 옮깁니다. 코드 변경은 실행 중 메모리에 적용되므로 켜거나 끈 직후에는 반드시 종료 후 재부팅하세요. ISO와 일반 저장 데이터는 이 패치가 수정하지 않습니다.

## 동작과 한계

3D 원근 투영 행렬의 가로 성분을 0.75배로 보정해 세로 시야를 유지하면서 가로 시야를 넓힙니다(Hor+). 가시 판정 범위도 보수적으로 확대합니다. 단순 화면 늘리기와는 다릅니다.

**2D 메뉴·HUD·로고·동영상은 원래 배치가 유지되므로 16:9 출력에서 가로로 늘어날 수 있습니다.** 모든 카메라·리플레이·경기장·게임 모드의 검증 완료를 의미하지 않으며, PS2 실기용 패치가 아닙니다. 확인 범위는 `validation/widescreen-runtime.json`에 기록합니다.

## 조사 출처와 제작

2026-10-11에 [공식 PCSX2 패치 저장소](https://github.com/PCSX2/pcsx2_patches) 및 [PCSX2 와이드 패치 포럼](https://forums.pcsx2.net/Thread-PCSX2-Widescreen-Game-Patches?pid=540611)을 조사했으나 이 북미판에 바로 사용할 수 있는 완성 코드를 찾지 못해, 보유 원본과 한글판의 투영 함수를 분석해 직접 작성했습니다. CRC 계산은 [PCSX2 Elfheader.cpp](https://github.com/PCSX2/pcsx2/blob/master/pcsx2/Elfheader.cpp)의 32비트 워드 XOR 방식과 일치합니다.

## 이후 릴리즈

**모든 새 빌드 릴리즈에 해당 CRC의 와이드 파일을 xdelta와 함께 첨부합니다.** `iso_build.py`가 ISO 완성 후 와이드 파일을 생성합니다. `prepare_widescreen_release.py`는 실제 ISO의 ELF CRC, 투영 코드 지문, 보조 코드 공간을 검사하므로 호환되지 않는 변경에는 실패합니다. 이때는 코드를 다시 분석해야 합니다.

`publish_release.py`는 ISO/xdelta/와이드 해시와 사용 설명을 검사하고 두 파일을 함께 게시합니다. 빌드마다 실행 검증 범위를 갱신하고 설치·비활성화 설명을 릴리즈 노트에 포함합니다.
