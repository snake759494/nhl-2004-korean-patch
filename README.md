# NHL 2004 (PS2 북미판, SLUS-20756) 비공식 한글패치

첫 공개 시험 릴리즈 **v0.9.0-test9**입니다. 로컬 TEST9 ISO와 동일한 결과를 만드는 xdelta 차분 파일을 배포합니다.

## 적용 방법

1. 아래 해시와 일치하는 원본 `NHL 2004 (USA).iso`를 준비합니다.
2. [릴리즈](https://github.com/snake759494/nhl-2004-korean-patch/releases/tag/v0.9.0-test9)에서 `NHL2004_PS2_KO_v0.9.0-test9.xdelta`를 받습니다.
3. xdelta3 또는 Windows의 xdeltaUI로 **원본 ISO에** 적용합니다.

```text
xdelta3 -d -s "NHL 2004 (USA).iso" "NHL2004_PS2_KO_v0.9.0-test9.xdelta" "NHL 2004 (USA) (Korean).iso"
```

이전 버전의 상태저장 대신 결과 ISO를 새로 부팅하세요. 적용 전후 ISO를 담을 충분한 여유 공간이 필요합니다.

## 한글화 범위

- 영어 전용 게임에 2바이트 한글 출력과 한글 1,036자 추가. 나눔스퀘어네오 ExtraBold 사용.
- 메뉴·도움말·경기 문구, 선수·감독·신인·팀·경기장 이름, 구단 뉴스, 제작진, 온라인 이용약관 번역.
- 실행 파일 표시 문구/이름 810곳, 화면 파일 직접 표시 문자열 1,097곳 반영.
- FIGHT, FIGHT!, POWERPLAY 문자 이미지 한글화.
- 경기 선수 이름의 바이트 경계 처리 및 원본과 유사한 테두리/그림자 적용.

## 남은 작업 및 확인 범위

구단·브랜드 로고와 사무실 명패·책·신문·포스터·장비 등의 이미지 영문, 일부 유럽/과거 팀의 통계 약칭은 남아 있습니다. 실황 음성·영상은 번역하지 않았습니다. 웹 주소, 실제 버튼 문자, 영문 입력용 키보드 문자와 내부 검색 키도 유지합니다. **모든 영문 제거가 완료된 버전은 아닙니다.**

사용자가 이전 TEST8에서 경기 진행, 선수 이름, 테두리 표시를 확인했습니다. 이번 TEST9의 추가 번역은 자동 검증 및 ISO 재추출 검사를 통과했지만, 실제 게임 진행은 아직 확인하지 않았습니다. 온라인 문구의 번역이 서비스 접속 가능 여부를 보장하지는 않습니다.
